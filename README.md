# Vision

DevCrypt is a collaborative cybersecurity and software engineering simulation designed to recreate how real technology teams investigate, debug, secure, and restore compromised systems.

Unlike traditional coding competitions or Capture-The-Flag (CTF) events, DevCrypt emphasizes teamwork, incident response, engineering decision-making, and cross-disciplinary problem-solving in Tech.

Participants do not simply answer questions or solve isolated coding problems. Instead, they work together to investigate a major cyber incident affecting a futuristic smart city called Metaverse City.

---

# Product Overview

DevCrypt transforms a career fair into a collaborative engineering simulation.

Teams of 4–6 participants act as an emergency response unit tasked with restoring critical city systems after a large-scale cyberattack.

Throughout the experience, teams investigate evidence, analyze system failures, fix technical problems, and recover encrypted fragments needed to unlock the Metaverse Core.

The game combines:

* Software Engineering
* Cybersecurity
* APIs
* Databases
* Incident Response
* Team Collaboration

into one continuous narrative.

---

# Problem Statement

Most technical competitions focus on a single skill area:

* Coding competitions focus on algorithms.
* CTFs focus on cybersecurity.
* Quizzes focus on knowledge recall.

But real-world technology organizations require teams to collaborate across disciplines to investigate incidents and restore services.

DevCrypt bridges this gap by simulating realistic engineering and security workflows in a competitive environment.

# Challenge Design Framework

Every vault follows the same structure.

## Part 1: Incident Brief

A short description explaining the situation.

## Part 2: Evidence

Participants receive:

* Logs
* Code snippets
* Emails
* API documentation
* Diagrams
* Screenshots

## Part 3: Investigation

Teams answer evidence-based questions.

Examples:

* What happened?
* Which system failed?
* What should be investigated next?

## Part 4: Engineering Challenge

Teams apply technical skills to solve the problem.

Examples:

* Debug authentication logic
* Patch SQL injection vulnerabilities
* Restore API communication
* Repair corrupted data

## Part 5: Fragment Reward

Successful completion awards an encrypted fragment.
